# Contributing

Thanks for taking an interest — genuinely. Bug reports and ideas are welcome.
Code changes are the one thing I'm handling myself for now, and there's a bit
more on that below.

## Issues

Feel free to open one — bug reports and feature requests are both fair game.

If it's a bug, these help a lot:

- A share link, or the sketch code that triggers it.
- Browser and OS.
- What you expected, and what happened instead.

Geometry with no lights in the scene renders black — that one's expected, and
catches most people at least once.

## Pull requests

I'm not able to take these right now, and I'd rather say so up front than leave
one sitting open. It's nothing to do with the code — fizzle has a lot of small
opinions baked into how its API feels, and I don't have a good way to review
against those without essentially rewriting the change. That's a poor trade for
whoever wrote it.

So if you've spotted something worth fixing, an issue really is the best way to
get it to me.

## Pace

fizzle is a passion project alongside my music and livecoding, so replies can
be slow, and occasionally very slow. If an issue goes quiet, that's almost always the reason
rather than disinterest. Some ideas I'll also end up setting aside because they
pull somewhere different from where I'm taking fizzle — never a comment on the
idea itself.
