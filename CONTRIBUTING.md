# Contributing

Thanks for taking an interest in fizzle 🙂 Bug reports and feature requests
are welcome, but I'm holding off on accepting PRs right now.

## Issues

Feel free to open both feature requests and bug reports.

If it's a bug, these help a lot:

- A share link / the sketch code that triggers it
- Browser and OS
- What you expected, and what happened instead

Note: Geometry with no lights renders black. That's intentional, but it can
catch some people off guard.

## Pull requests

I'm not able to take these right now. It's nothing to do with the code: fizzle
has a lot of small opinions baked into how its API feels, and I don't have a
good way to review against those without essentially rewriting the change.

Rather than risk good code going to waste, I'm asking that you please open a
feature request instead. I'm always happy to take a look.

## Pace

fizzle is a passion project alongside my music and livecoding, so replies can
be slow, and occasionally _very_ slow. If an issue goes quiet, that's almost
always the reason rather than disinterest. Some ideas I'll also end up setting
aside because they pull somewhere different from where I see fizzle going.
Never a comment on the idea itself.
